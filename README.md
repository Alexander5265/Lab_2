# Задание 1.

## Задача 10.

### Текст задачи.

Получить список из произведений цифр соответствующих чисел, хранящихся в
исходном списке.

### Алгоритм решения.

1. Создается функция product, в которой каждое полученное число разделяется на цифры, а затем эти же цифры превращаются в отдельные числа.
2. Полученные числа умножаются друг на друга, конечной результат запоминается.
3. Создется функция getProducts, которая получает введеный пользователем список чисел. Затем product применяется к каждому числу исходного списка, засчет List.map.
4. Создается список чисел, введенных пользователем.
5. Создается переменная result, хранящая в себе готовый, уже перемноженный список.
6. Производится вывод списка на экран.

# Задание 2.

## Задача 10.

### Текст задачи.

Список содержит строки, обозначающие двоичные числа от 1 до 9. Найти в
десятичной системе счисления сумму элементов списка.

### Алгоритм решения.

1. Программа просит пользователя ввести числа.
2. В main введенная строка разбивается на список.
3. Каждое числа в функции binToDec переводится из двоичного в десятичное.
4. Все десятичные числа скалыдваются с помощью List.fold (List.fold: сложение, начальное_значение, список).
5. Результат выводится на экран.
